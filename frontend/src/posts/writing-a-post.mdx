Create `src/posts/<slug>.mdx` with this header:

```yaml
---
title: My post
date: 2026-10-01
excerpt: One line shown in the list.
tags: [thing, other]
draft: true   # optional; hidden in production builds
---
```

The filename is the URL slug. Delete `draft` when it's ready.
